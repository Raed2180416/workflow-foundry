# tier-0 form conformance fixtures, version 1

The layout is OpenUI's conformance-fixture layout (`spec/fixtures/1.0` at openui `39ce989`, read statically; nothing was
copied): one folder per case, `<area>/<NNN-short-name>/`. File formats and comparison rules are in
[`../../fixtures.mjs`](../../fixtures.mjs) and [`../../README.md`](../../README.md). The expected values were written by
hand from the subset rules. `compile/*/expected.html` was generated by `renderForm` and reviewed; regenerate it with
`node tools/ui/fixtures.mjs --write-html` and review the diff. The golden pages write the spec hash as `{{spec}}`, since
it binds the semantics code (`compile.mjs` `SEMANTICS`). A case whose schema uses `pattern` sets `"allowPattern": true`
in `input.json`; without it the compiler refuses `pattern`, as the engine does.

| area | protects | files |
|---|---|---|
| `compile` | the schema → form mapping (field names, components, value types, requiredness, groups, warnings) and the exact page | `input.json`, `expected.json`, `expected.html` |
| `refuse` | that every schema outside the subset is refused with its own code, at the right path, and never flattened | `input.json`, `expected.json` |
| `submit` | the formState adapter, the browser route and the host validator: typed answers out, structural errors otherwise | `input.json`, `interactions.json` |

The cases are drawn from the patterns named in OPENUI.md §8 B1, plus the subset's edge cases:
- **compile:** P32 approval (`001`), L0 row 17 ask (`002`), P10 menu (`006`), P55 ask-validate (`011`), P09 review-queue
  item (`010`), an exception screen (`012`), and the E-bed object answers E2 hold release (`007`), E5 dispute
  disposition (`008`) and E7 SLA reassignment (`009`).
- **submit:** OpenUI's `"12abc"` (`002`), number syntax (`003`), envelope and shape attacks (`005`, `009`, `010`), groups
  (`011`), integer precision (`012`), code-point length (`013`) and pattern anchoring (`014`).
- **refuse, added by the G21 review fixes (2026-10-14):** `pattern` off by default (`034`), the pattern-bound bypasses
  the review found (`035` `[^]` hiding a nested quantifier, `036` small counted quantifiers, `037` a chain of `?`),
  `pattern` on an enum (`038`), and options a person cannot tell apart (`039`).
