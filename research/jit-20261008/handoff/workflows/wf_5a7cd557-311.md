**Pass rule:** pass when field accuracy over matched people is at least 0.97, pairwise cluster F1 is at least 0.95, and extra and missing people are each at most floor(0.02·E), where E is the number of real people. Below 50 people that allows none, which covers d1–d3. Score = harmonic mean(field accuracy over all people, pair F1) × (1 − (extra + missing)/E).

**Things that differ from the brief:**
- **Extra output field.** The output includes `source_rows` (all row ids merged into a person). The cluster F1 needs it; `entity_id` alone doesn't say which rows belong together.
- **`package.json` shim.** On Node 24.21, `node --test beds/records/` does not expand a directory; it tries to load it as a module and fails. The small `package.json` in my directory points `main` at the test file so that exact command works. Other bed families will hit the same problem.
