# Worst cases for orchestrating nodes, agents and subagents (2026-10-21)

*Owner ask (2026-10-21): make node/agent/subagent orchestration "completely robust … keep in mind genuine worst-case real-world
use … our system should do all the plumbing so the user has the most seamless experience". This catalogue is the attack
surface. Each row: a concrete scenario; what Foundry does **today** (file:line in this repository, or "unhandled"; **chaos Xn**
is the scenario in `experiments/orch/scenarios/` that tested it, result in [chaos/MATRIX.md](chaos/MATRIX.md)); what the best
prior art does ([PRIOR-ART.md](PRIOR-ART.md), same tags); and the behaviour Foundry needs. Ranking and fixes:
[GAPS-AND-PLAN.md](GAPS-AND-PLAN.md). CLI facts: [PROBES.md](PROBES.md). Development/diagnostic evidence; no sealed claim.*

**Scope of "our system".** Two orchestration layers exist and both are attacked: the **src runtime** (`src/runtime.mjs`: typed
IR runs with map/loop/wait/human/agent/code nodes, the store, cancel/stop-all, children reaping, journal resume) and the
**flow-v3 layer** (`experiments/jit/flow-v3.mjs` compiled solvers with `flow.call`/`agent`/`wide`, hosted by
`run-compiled.mjs`, `call-host.mjs` and the gateway `experiments/lib/services.mjs`), plus the experiment runners
(`experiments/lib/runner.mjs`, `experiments/autobench/run.mjs`).

**This week's real incidents** (evidence, cited where they apply): (I1) a full disk killed runs mid-write
(`research/automationbench-20261014/runs/a1-dev60-dn/NOTE.md:6-8`); (I2) usage limits killed 4-12 agents per workflow mid-run
(this session's Workflow tool; `DEV60-A0-A1.md:65-66`); (I3) a CLI auto-update 2.1.300 -> 2.1.306 changed the harness
fingerprint between runs (`DEV60-A0-A1.md:101-102`); (I4) concurrent agents edited the same file (`run.mjs`) and needed 3-way
merges; (I5) a `pgrep | xargs kill` by one agent may have killed another agent's bridge; (I6) rate-limit storms produced 24
fault records; (I7) a $0-priced model ran 97 M tokens because budgets were in dollars (`src/executors/openai-chat.mjs:18,55`
added a token budget afterwards); (I8) a runner fix changed the harness manifest and a resume was then refused
(`a1-dev60-dn/NOTE.md:11-15`).
