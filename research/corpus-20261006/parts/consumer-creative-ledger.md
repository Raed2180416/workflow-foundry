# Consumer-creative cluster: acquisition ledger (corpus-20261006)

Cluster scope: consumer and creative workflow graphs: Apple Shortcuts, ComfyUI node graphs, Home Assistant automations/scripts/blueprints, plus IFTTT applets as a small supplementary consumer-automation source (not one of the three sources named for this cluster; kept to 25 items, graph-only). Items: `parts/consumer-creative.jsonl` (`foundry-corpus-item/1`). Raw downloads only under `/opt/corpus/{apple-shortcuts,comfyui,home-assistant,ifttt}` and working files under `/opt/corpus/consumer-work` (outside git). Converters and fetchers: `scripts/consumer-creative-*.py`.

All corpus content was treated as untrusted data and nothing downloaded was executed: ComfyUI and IFTTT pages were parsed as JSON / with regexes, Home Assistant YAML with a PyYAML `SafeLoader` subclass that turns every custom tag (`!input`, `!secret`, `!include`) into an inert placeholder, native shortcuts with `plistlib`, the WorkflowLLM pseudo-Python transcriptions with a tolerant line/indent parser (never `exec`/`eval`/`import`), and `statistics.pkl` with an Unpickler whose `find_class` admits only builtin container types. Git clones were shallow, blobless and sparse with hooks, LFS and submodules disabled. No instruction found inside corpus text was followed.

Retrieved 2026-10-06 (licence re-check and selection 2026-10-07). Status: **development/diagnostic corpus**, not sealed evaluation data. Total selected: **273** items; **159** redistributable as normalised graphs, **114** not (unknown licence, non-commercial licence or terms of service). For non-redistributable items git keeps only the URL, title, a written description, the derived graph (node types, categories, effects, type-level summaries; no prompts, entity ids, message text or code) and the features.

## Reproduction

```sh
S=research/corpus-20261006/scripts; V=/opt/corpus/.venv-consumer/bin/python   # uv venv, pyyaml==6.0.3 (consumer-creative-requirements.txt)
python3 -I $S/consumer-creative-fetch-hf.py                 # WorkflowLLM + 3 HF ComfyUI collections at pinned revisions
python3 -I $S/consumer-creative-fetch-git.py comfy-core      # Comfy-Org/workflow_templates, ComfyBench, execution-inversion demo
python3 -I $S/consumer-creative-fetch-git.py comfy-registry 60   # example workflows of the most-downloaded registry node packs
python3 -I $S/consumer-creative-fetch-git.py ha && python3 -I $S/consumer-creative-fetch-git.py ha-docs
python3 -I $S/consumer-creative-fetch-haforum.py 5          # Blueprint Exchange all-time top topics (250)
python3 -I $S/consumer-creative-fetch-icloud.py 120         # native .plist of iCloud links cited in WorkflowLLM seeds
python3 -I $S/consumer-creative-ifttt.py fetch 300
python3 -I $S/consumer-creative-shortcuts.py; python3 -I $S/consumer-creative-shortcuts-native.py
python3 -I $S/consumer-creative-comfyui.py; $V -I $S/consumer-creative-homeassistant.py; python3 -I $S/consumer-creative-ifttt.py normalize
python3 -I $S/consumer-creative-assemble.py && python3 -I $S/consumer-creative-ledger.py
```

Live sources (Blueprint Exchange, iCloud share records, IFTTT pages, the ComfyUI registry listing) will differ on a later date; each item's `source.revision` pins a git SHA, HF revision, iCloud `recordChangeTag` or the sha256 prefix of the raw bytes actually used.

## Selection

`consumer-creative-assemble.py` (deterministic). Per platform, in order: **coverage** (each named acquisition source that would otherwise be missing gets its top items: ComfyBench, the three HF ComfyUI collections, HA docs examples, Blueprint Exchange, EPMatt blueprints, native iCloud shortcuts); **complex** (top by the complexity score `nodes + 2*branching + 3*loops + 4*humanSteps + 2*subworkflows + 2*|async| + 1.5*|connectors| + 3*hasCode + 2*hasModelCalls`, with a per-source cap); **feature** (top-2 not yet selected for each of loops, human steps, model calls, code, sub-workflows, wait, poll, webhook, schedule, branching>=5); **representative** (uniform sample ordered by sha256('consumer-creative-20261006:'+id)). Near-duplicates are suppressed: identical node-type multiset and edge count, or within one source a weighted Jaccard >= 0.85 of node-type multisets at similar size (variant files such as the JakeUpgrade single-GPU/multi-GPU pairs), or for Apple Shortcuts the same normalised title. Graphs with fewer than 2 or more than 1000 nodes are not selected; the oversize ones stay in the candidate files and are listed below. The complexity-ranked strata over-represent very large consumer graphs on purpose; the representative stratum is the one to use for base rates.

## Blocked, failed or not attempted

- **Gourieff/comfyui-reactor-node** (ComfyUI registry pack, 570809 downloads): anonymous `git clone` asks for credentials (`fatal: could not read Username`, re-probed 2026-10-07 with `git ls-remote`): the repository is not publicly reachable (removed, disabled or private). No substitute was taken.
- **GitHub REST API** (`api.github.com`) for repositories outside this session is blocked by the proxy; repository metadata therefore comes from shallow blobless sparse clones, `git ls-remote` and LICENSE files read from the pinned tree or raw.githubusercontent.com. Licences are what the LICENSE file says; GitHub's licence detection was not consulted.
- **iCloud share records**: failed: HTTP Error 500: Internal Server Error 1, failed: [Errno 104] Connection reset by peer 1 of the 120 sampled ids; 710 further cited ids were not fetched (sample cap). Signed (AEA) shortcut assets were not downloaded; only the unsigned plist variant was used.
- **Blueprint Exchange**: 34 of the top 250 topics have no importable blueprint YAML: no blueprint import link and no YAML code block with `blueprint:` in the first post. Only the all-time top 250 topics were read.
- **ComfyBench task set**: no reference workflows for the 200 tasks; ComfyBench evaluates by execution pass plus a VLM judgment, so no per-item oracle is available. Repository has no LICENSE (licence `unknown`).
- **WorkflowLLM synthesised data** (`synthesized_data.json`, ~630 MB of model-generated workflows) was not used: it is synthetic, not observed workflows.
- **Not attempted in this pass**: Apple's Shortcuts Gallery and RoutineHub directly (the WorkflowLLM seeds and their iCloud links already include RoutineHub-shared shortcuts), OpenArt / Civitai / comfyworkflows.com ComfyUI sharing sites, the Home Assistant Community Store and blueprint repositories beyond the 15 listed. Their terms and bulk-access options were not assessed.

## Caveats

- WorkflowLLM items are graphs of a *transcription* (the dataset authors converted each shortcut plist to pseudo-Python and wrote a natural-language query with a model). Node order, branches and data references follow that transcription; variable plumbing (Get/Set Variable, Comment, Nothing) is folded into data edges. The native iCloud items come straight from the plist (WFControlFlowMode grouping, OutputUUID references) and are the cross-check for that path.
- Home Assistant graphs inline YAML anchors/aliases and expand `choose`/`if`/`repeat`/`parallel`; where a file uses aliases the item notes say how many. Jinja templates are counted, not evaluated. Blueprint `!input` placeholders stay placeholders, so a blueprint graph is the template, not one instantiation.
- ComfyUI graphs drop UI-only nodes (notes, labels, primitive widgets), collapse Reroute/SetNode/GetNode wires, inline each subgraph definition once (instances stay as `subworkflow` nodes wired to the inlined body), and keep bypassed/muted nodes (flagged in the summary). `hasModelCalls` is true for local diffusion/encoder/vision nodes as well as hosted API nodes; hosted ones are named in `connectors` as `api:<provider>`.
- Node categories, effects and domains come from name-based rules in the converters, so they are approximate. Two misclassifications found while spot-checking (ComfyUI `...TextEncodeNode` matching the code rule; LivePortrait `ExpressionEditor` as code) were fixed before the final selection; others may remain.
- No item has an executable oracle: Shortcuts run only on Apple devices, HA automations need a live instance (a mocked-execution oracle over HA's script engine is plausible future work), ComfyUI outputs are generative.
